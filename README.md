# Guess My Number Game 🎯

A fun and interactive number guessing game built with HTML, CSS, and JavaScript.

## Features

- Responsive design using CSS Grid and Flexbox
- Dynamic UI updates with JavaScript
- Real-time feedback on guesses

## How to Play

Enter a number between 1 and 20. The game will tell you if your guess is too high, too low, or correct.
